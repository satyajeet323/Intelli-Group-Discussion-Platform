# INTELLI BOT (RoxGD) — Project Context

## Overview
**INTELLI BOT** is an AI-powered Group Discussion (GD) Practice and Evaluation Platform engineered to bridge the preparation gap for job interviews, academic assessments, and public speaking. The system blends real-time multi-party audio/video conferencing with acoustic signal processing and generative AI to deliver instant, objective, and multi-dimensional feedback on verbal communication.

## Core Value Proposition
- **Multi-party Practice:** Real-time WebRTC group rooms where peers can debate topics, coordinate speaking turns, and evaluate each other's performance.
- **Solo AI Training Partner:** An on-demand 1-on-1 conversational bot powered by Groq Llama 3 for low-latency dialogue and ElevenLabs for natural voice synthesis.
- **Deep Acoustic & Linguistic Analysis:** Automated transcription via OpenAI Whisper, filler word quantification via a custom PyTorch CRNN, prosody metrics (WPM, pause ratios, nPVI) via Librosa, and semantic relevance via SBERT.
- **Generative Assessment:** Structured multi-criteria scoring and personalized feedback generated by Google Gemini.
- **Enterprise & Admin Readiness:** Dynamic API key rotation, RBAC, session history, and full audit logging.

## Technology Summary
| Layer | Tech Stack | Responsibility |
|---|---|---|
| **Frontend** | React 19, TanStack Start & Router, TailwindCSS v4, Radix UI | Responsive UI, video conferencing tiles, real-time waveform visualizers, report charts |
| **Backend** | Node.js (ESM), Express 4, Socket.IO 4, Mongoose 8, MongoDB | API Gateway, WebRTC signaling mesh, auth (JWT), in-memory session roster, reports |
| **ML Engine** | Python 3.10+, FastAPI, PyTorch 2.5, Whisper, SBERT, Librosa | Audio normalization, speech-to-text, CRNN filler detection, semantic similarity, Gemini scoring |
| **External AI** | Google Gemini 1.5/2.0, Groq (Llama 3), ElevenLabs TTS | Dynamic topic generation, dialogue generation, realistic voice synthesis, evaluation |
