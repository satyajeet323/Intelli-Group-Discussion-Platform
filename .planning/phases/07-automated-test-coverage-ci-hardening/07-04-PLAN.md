# Plan 07-04: CI Workflow Modernization & Hardening

## Objective
Update `.github/workflows/ci.yml` and `.github/workflows/pr-checks.yml` to target the actual project directories (`ml-server/` instead of legacy `server/*.py`), run the newly created unit/integration test suites across all 3 layers, fix environment variable mappings, and eliminate failure suppression.

## Context
- `ci.yml` and `pr-checks.yml` contain outdated paths:
  - Cache and dependencies reference `server/requirements.txt` instead of `ml-server/requirements.txt`.
  - Python lint and syntax checks run against `server/*.py` where no Python files exist.
  - Flask is installed instead of FastAPI.
  - Integration tests use obsolete variable `PYTHON_SERVICE_URL` instead of `ML_SERVER_URL`.
  - Integration test job has `continue-on-error: true`.
- Now that `server/`, `client/`, and `ml-server/` have standard test commands (`npm test`, `pytest`), CI can execute real tests with full fidelity.

## Tasks
1. **Modernize `.github/workflows/pr-checks.yml`:**
   - Update path filter for python to `'ml-server/**'` instead of `'server/*.py'`.
   - Update `python-checks` job:
     - Setup Python 3.11.
     - Working directory: `ml-server`.
     - Install requirements and test deps (`pip install -r requirements.txt`).
     - Run `pytest tests/`.
   - Update `frontend-checks` job:
     - Add `npm test` step after linting and typecheck.
   - Update `backend-checks` job:
     - Add `npm test` step.
2. **Modernize `.github/workflows/ci.yml`:**
   - **Job 1 (Lint):**
     - Target `ml-server/` for Python linting (`flake8 ml-server --max-line-length=120`, `black --check ml-server`).
     - Use `ml-server/requirements.txt` for pip cache.
   - **Job 3 (Frontend Build & Tests):**
     - Add `npm test` to run Vitest suite before or after build.
   - **Job 5 (Python Service Validation):**
     - Working directory: `ml-server`.
     - Install requirements (`pip install -r requirements.txt`).
     - Run `pytest tests/`.
   - **Job 6 (Security Scan):**
     - Run `pip-audit -r ml-server/requirements.txt`.
   - **Job 7 (Integration Tests):**
     - Map `ML_SERVER_URL: http://localhost:8000` (remove obsolete `PYTHON_SERVICE_URL`).
     - Run backend `npm test` against live test MongoDB service.
     - Remove `continue-on-error: true` so failed tests correctly block CI gate.
3. **Validate GitHub Workflow Syntax:**
   - Verify YAML structure, action versions, and variable names.

## Verification Criteria
- [ ] Workflow YAML files parse cleanly with no missing actions or invalid keys.
- [ ] No references remain to nonexistent `server/requirements.txt` or `server/*.py`.
- [ ] `ci-gate` requires all tests (frontend vitest, backend integration, ML pytest) to succeed.
