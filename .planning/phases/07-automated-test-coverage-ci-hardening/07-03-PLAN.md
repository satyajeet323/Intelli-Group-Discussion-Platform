# Plan 07-03: Frontend Testing with Vitest

## Objective
Introduce automated unit and component testing to the `client/` application using Vitest and React Testing Library, verifying critical utilities, hooks, and UI components.

## Context
- `client/` is built with React 19, Vite 7, and TypeScript.
- No testing libraries or test scripts currently exist in `client/package.json`.
- Essential components (`ControlBar`, `LeaveDialog`, `AppSidebar`) and helper modules (`lib/utils.ts`, `lib/api.ts`) should have automated test coverage to prevent UI regressions.

## Tasks
1. **Install Test Dependencies in `client/`:**
   - Dev dependencies: `vitest`, `@testing-library/react`, `@testing-library/jest-dom`, `@testing-library/user-event`, `jsdom`.
2. **Configure Vitest (`client/vite.config.ts` or `client/vitest.config.ts`):**
   - Add test configuration with `environment: 'jsdom'`, `globals: true`, and `setupFiles: ['./src/test/setup.ts']`.
3. **Create Test Setup & Polyfills (`client/src/test/setup.ts`):**
   - Import `@testing-library/jest-dom/vitest`.
   - Mock browser APIs not in jsdom (e.g. `window.matchMedia`, `HTMLMediaElement.prototype.play`).
4. **Implement Key Unit & Component Tests:**
   - `client/src/lib/utils.test.ts`:
     - Test `cn()` class merger across conflicting Tailwind classes.
   - `client/src/components/ui/button.test.tsx`:
     - Test Radix/Tailwind button rendering, variant styles, and click handlers.
   - `client/src/components/group-session/LeaveDialog.test.tsx`:
     - Test modal display, confirmation callback on leave, and cancellation.
5. **Add Package Scripts in `client/package.json`:**
   - `"test": "vitest run"`
   - `"test:watch": "vitest"`
6. **Verify Local Execution:**
   - Run `npm test` inside `client/` to verify tests pass cleanly.

## Verification Criteria
- [ ] `npm test` runs in `client/` using Vitest and passes.
- [ ] TypeScript type-checking (`npx tsc --noEmit`) passes with test files included.
- [ ] Fast execution (< 5 seconds).
