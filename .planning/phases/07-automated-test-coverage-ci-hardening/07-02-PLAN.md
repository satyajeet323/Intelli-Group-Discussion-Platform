# Plan 07-02: FastAPI ML Microservice Pytest Suite

## Objective
Establish an automated test suite for `ml-server/` using `pytest` and `httpx` (`TestClient`) to validate endpoints, payload schemas, and core prosody/scoring calculations without requiring GPU hardware or live Gemini API access during fast CI execution.

## Context
- `ml-server/` currently has no automated tests.
- CI pipeline previously tried to test Python files in `server/` using obsolete Flask checks.
- Need fast unit tests that execute in seconds in CI and fail early if route contracts or schema changes break.

## Tasks
1. **Update `ml-server/requirements.txt`:**
   - Add test dependencies: `pytest>=8.0.0`, `pytest-asyncio>=0.23.0`, and `httpx>=0.27.0`.
2. **Create Test Directory Structure (`ml-server/tests/`):**
   - `__init__.py`: Package marker.
   - `conftest.py`: Fixtures providing `TestClient(app)` with mocked heavy models or offline test stubs.
   - `test_health.py`:
     - Test `GET /health` endpoint returns 200 and expected JSON structure (`status`, `models`, `version`).
   - `test_schemas.py`:
     - Test Pydantic models in `ml-server/schemas/` (`AudioAnalysisResponse`, `TranscriptScoreRequest`, `SessionEvaluationRequest`, etc.) with valid and invalid payloads.
   - `test_scoring.py`:
     - Test prosody scoring helpers in `services/scoring_service.py` and `services/audio_service.py` using synthetic audio metrics (duration, syllables, pause ratios, WPM).
     - Test fallback response formatting when Gemini API returns malformed JSON or errors.
3. **Add pytest configuration (`ml-server/pytest.ini`):**
   - Configure test discovery paths and asyncio mode (`asyncio_mode = auto`).
4. **Verify Local Execution:**
   - Run `pytest` inside `ml-server/` to verify tests pass quickly without errors.

## Verification Criteria
- [ ] `pytest` runs in `ml-server/` and passes 100% of tests.
- [ ] Tests execute in < 10 seconds without requiring external API network calls or GPU weights.
- [ ] Invalid schema requests return expected HTTP 422 Unprocessable Entity responses.
